# Cambrian Private Pilot Outreach Kit

## Goal

Find 5-10 people who already use AI for coding and show them the Auth Bug Core worker pack flow.

## What We Are Testing

- Can they understand Cambrian in 60 seconds?
- Do they understand "AI worker pack"?
- Do they want to install a worker pack into their existing AI workflow?
- Can they complete or understand the Auth Bug Core Golden Path?
- Where do they get confused?
- Would they pay for this if it worked on their project?

## Pilot Scope

- Auth Bug Core only
- local install
- pack activation
- pack start
- prepared AI reply first run
- validation handoff
- local proof/outcome summary

## Out of Scope

- marketplace
- remote registry
- payment
- vNext
- rollout
- canary/challenger
- fully automatic coding promises
- provider API integration

## Success Criteria

### Minimum success

- 5명에게 데모
- 3명이 60초 안에 제품을 자기 말로 설명 가능
- 2명이 자기 프로젝트에 연결해보고 싶다고 말함
- 1명이 특정 worker pack을 요청함

### Strong signal

- 5명 중 3명이 실제 설치/테스트를 원함
- 1명 이상이 돈을 낼 수 있다고 말함
- 1명 이상이 다른 사람을 소개함
- 반복적으로 같은 pack 요청이 나옴

### Kill / pivot signal

- 대부분이 "그냥 프롬프트랑 뭐가 달라?"라고 느낌
- pack install 개념을 이해하지 못함
- CLI가 너무 어려워서 데모 이후 시도 의향 없음
- Auth Bug Core가 너무 좁거나 가치가 약하다고 느껴짐

## Pilot Run

1. Send one invite message.
2. Show the one-minute pitch.
3. Run the five-minute Auth Bug Core walkthrough.
4. Ask the interview guide questions.
5. Fill one feedback form immediately after the call.
6. Record any blockers with the issue intake template.
7. Update a private copy of the tracker template.
