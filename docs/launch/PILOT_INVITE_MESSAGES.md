# Pilot Invite Messages

## Korean DM short

```text
형님, 제가 "이미 쓰는 AI에 AI 작업반을 설치해서 일을 맡기는 도구"를 만들고 있습니다.

첫 데모는 Auth Bug Core라는 로그인/인증 버그 수정 작업반입니다.
5분만 보여드리고, 이해되는지 / 써보고 싶은지 / 어디가 이상한지 피드백 받고 싶습니다.

부담 없이 제품 욕해주셔도 됩니다.
```

## Korean slightly formal

```text
안녕하세요. 제가 Cambrian이라는 도구를 만들고 있습니다.

Cambrian은 사용자가 이미 쓰는 AI에 검증된 AI 작업반을 설치하고,
그 작업반에 실제 일을 맡기고,
결과를 검증하는 로컬 실행 엔진입니다.

현재는 Python + pytest 기반 로그인/인증 버그 수정용 Auth Bug Core 작업반을 데모하고 있습니다.
10분 정도 짧게 보여드리고 솔직한 피드백을 받고 싶습니다.
```

## English short

```text
I'm building Cambrian -- a tool that installs AI worker packs into the AI you already use.

The first product run is Auth Bug Core: a worker pack for Python + pytest auth/login bug fixes.

I'd love to show you a 5-minute product walkthrough and get blunt feedback on whether this makes sense, where it feels confusing, and whether you'd ever use it.
```

## Follow-up message

```text
감사합니다. 피드백 기준은 딱 세 가지입니다.

1. 한 문장으로 이해되는지
2. 실제로 써보고 싶은지
3. 어디서 막히거나 과장처럼 느껴지는지
```

## Do not say

- 완전 자동 개발
- 개발자를 대체
- 무조건 버그 고침
- 검증 완료된 제품
