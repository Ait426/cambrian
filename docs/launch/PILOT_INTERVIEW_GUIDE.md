# Pilot Interview Guide

## Before walkthrough

1. 지금 AI로 코딩할 때 가장 자주 막히는 지점은 무엇인가요?
2. 직접 프롬프트/에이전트/워크플로를 짜는 게 쉽나요, 어렵나요?
3. 반복적으로 AI에게 시키는 작업이 있나요?
4. AI 결과를 믿고 적용하기 전에 보통 어떻게 검증하나요?

## During walkthrough

Observe:

- 제품 한 문장을 듣고 바로 이해하는가?
- Auth Bug Core가 뭔지 이해하는가?
- pack install / activate / start 흐름이 자연스러운가?
- CLI가 너무 어렵게 느껴지는가?
- 웹 hiring desk 비유가 먹히는가?
- local runtime이 설치, 작업 전달, 검증, proof를 한다는 경계가 이해되는가?

Facilitator check:

- Can the participant explain the AI worker pack concept?
- Does pack install / activate / start feel like a natural workflow?
- Do they ask about money only after understanding the workflow?
- Could this fit a company/team workflow, or only a solo run?

## After walkthrough

1. 이 제품을 한 문장으로 설명하면 뭐라고 하시겠나요?
2. 가장 헷갈린 단어는 무엇인가요?
3. "AI 작업반 설치"라는 표현이 이해되나요?
4. 직접 써보고 싶은 작업반이 있나요?
5. 지금 당장 돈을 내야 한다면 무엇이 있어야 하나요?
6. Auth Bug Core 말고 어떤 pack이 있으면 좋겠나요?
7. 이걸 본 뒤 가장 큰 의심은 무엇인가요?
8. 가장 좋았던 장면은 무엇인가요?

## Buying signal questions

1. 이걸 실제 프로젝트에 연결해보고 싶나요?
2. 만약 설치를 도와준다면 테스트해보실 건가요?
3. 이게 잘 되면 월 얼마까지 낼 수 있을 것 같나요?
4. 회사/팀에서 쓸 수 있을 것 같나요?
5. 누구에게 소개해줄 수 있나요?

## Interview notes

- 답을 유도하지 않는다.
- "써보고 싶다"와 "신기하다"를 구분한다.
- 가격 질문은 마지막에 한다.
- proof/validation이 믿겼는지 반드시 확인한다.
