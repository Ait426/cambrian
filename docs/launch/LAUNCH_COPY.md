```bash

cambrian pack start "로그인 에러 수정해"
```

## Scope discipline

Use these phrases:

- worker pack
- Auth Bug Core
- local runtime
- canned first run
- validated proposal
- local proof

Avoid these phrases:

- unconditional success claims
- all-purpose AI company
- public benchmark winner without local evidence
