# Cambrian Launch Product Run Assets

## Product Message

Cambrian installs AI worker packs into the AI you already use.

이미 쓰는 AI에 검증된 AI 일꾼을 설치하세요.

## Primary Product Run

Auth Bug Core worker pack

Best for Python + pytest + narrow auth/login bug fixes.

## Boundary

The web page is the hiring desk.

Your local Cambrian runtime does the install, job handoff, validation, and proof.

## Assets

- Web landing screenshot
- Auth Bug Core pack page screenshot
- README quickstart screenshot
- Terminal: pack show
- Terminal: install pack
- Terminal: pack activate
- Terminal: pack start
- Terminal: job ingest
- Terminal: job validate
- Terminal: proof/outcome summary

## Do Not Show

- API keys
- private local absolute paths
- raw user data
- fake proof metrics
- registry / rollout / vNext advanced commands
