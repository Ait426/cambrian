# Asset Privacy Checklist

## Terminal

- [ ] No API keys
- [ ] No private absolute paths
- [ ] No personal username path
- [ ] No raw private project source
- [ ] No fake proof numbers

## Web

- [ ] No unsupported proof claim
- [ ] No marketplace/payment claim
- [ ] Web/local runtime boundary shown

## First-Run Fixture

- [ ] Canned AI reply clearly marked
- [ ] No real provider call required
- [ ] Fixture path is safe to show

## Proof

- [ ] Local/fixture proof is clearly labeled
- [ ] No unconditional success or unsupported best-performance claim

## Recording

- [ ] Terminal prompt does not show a private home path
- [ ] Browser chrome does not show personal accounts
- [ ] Output excerpts are short and readable
- [ ] Advanced registry / rollout / vNext commands are not centered
