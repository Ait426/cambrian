  • 브라우저는 provider API key를 저장하지 않습니다.
  • API 연결은 서버의 /api/builder/guide gateway가 담당합니다.
  • 응답은 질문, 추천 보기, contract_patch, 위험 경고, 다음 선택지만 허용합니다.
  • 장애 시 fallback은 local_template_recommendation입니다.
